# 教师/实验室试用方案（验证付费意愿）

> 目的：回应终审建议——"找少量实验室或课程教师试用，验证他们是否愿意为审计、教学或部署服务付费。客户反馈比继续增加版本号更能回答商业价值问题。"
> 定位：**需求验证**，不是销售冲刺。目标是在 2–4 周内拿到 5–10 份结构化反馈。
> 日期：2026-09-27

## 1. 我们提供什么（全部已存在）

| 资产 | 形态 | 试用中的角色 |
|---|---|---|
| 在线 demo（FlyWire / MaleCNS 双数据集） | 浏览器零安装 | 课堂演示 5 分钟上手 |
| 中文知识库（`knowledge/`） | 8 篇文档 | 备课参考、学生阅读材料 |
| 技术报告 v5.1 + 答复信 | PDF | 方法论教学案例（"如何诚实地做计算研究"） |
| 审计与复现管线（8 个探针脚本 + 固定数据获取） | 命令行 | 研究生计算课的实训作业素材 |
| 中文长文（知乎风格） | 稿件 | 教师转发给学生的导读 |

## 2. 目标试用者（按优先级）

1. **大学神经科学/计算神经科学课程教师**（1–2 节课用得上"可交互的连接组"）：最痛的点是"学生看不到真实数据长什么样"。
2. **做连接组/计算方向的实验室 PI**：研究生需要数据管线实训；他们最能评价审计工具的价值。
3. **科技馆/科普机构教育岗**：展项需要零安装、可互动、有科学诚实说明的内容。

渠道：先熟人（老师自己的学术网络）→ 知乎长文文末招募 → awesome-fly/Fly Brain Hub 社区私信。

## 3. 试用设计（2 周为一轮）

- **第 0 天**：发一页纸材料（本方案的精简版 + demo 链接 + 长文链接）+ 30 分钟线上 walkthrough。
- **第 1 周**：教师自行在课堂上/组会上使用；我们提供异步支持（微信群/issue）。
- **第 2 周**：30 分钟结构化访谈（问题见下）。
- 目标样本：第一轮 3–5 人；两轮合计 5–10 人即停，不追求统计显著，追求方向性信号。

## 4. 访谈问题（付费意愿核心）

1. 你在什么场景用了它？学生/同事的反应如何？
2. 如果这是付费产品，哪个部分你最不愿意失去：① 在线互动 demo ② 备课材料与讲义 ③ 审计/复现工具 ④ 部署与定制支持？
3. 以下哪种形态你会真的掏钱：按学期订阅的教学包 / 一次性定制部署 / 按项目计费的审计报告 / 都不会？
4. 心理价位（如果有）：每学期 ___ 元 / 每项目 ___ 元？
5. 你会向同事推荐吗？推荐时怎么说？（NPS 式一问）

**判定信号**：出现 ≥2 个"主动问价格/主动想继续用"的反馈 → 值得投入做产品化；全是"挺有意思但不需要" → 回到纯开源社区路线，不再投商业化精力。

## 6. 边界与诚实声明

- 当前 demo 是**工程演示**，不是神经科学教学软件成品；访谈中如实说明感觉/读出为人工接线、无 VNC（FlyWire 模式）、不代表"意识上传"。
- FlyWire 数据 CC BY-NC 4.0：试用本身是非商业研究/教学用途，OK；一旦收费，涉及 FlyWire 数据的部分需重新评估许可（MaleCNS 模式 CC BY 4.0 无此限制）。
- 本方案不预测收入；它的唯一产出是"有没有人为它停留/付钱"的证据。
