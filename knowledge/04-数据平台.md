# 04 · 数据平台手册

> 来源：基于 2026-09-17 调研整理

果蝇连接组与神经科学主要数据平台逐一手册：URL、数据内容、注册访问方式、API/客户端、免费与否、典型查询、官方文档。

> **名称勘误**：部分资料（含本知识库任务书）写作 "Codon / codon.flywire.ai"——经 2026-09-17 实测该域名不存在。FlyWire 的网页数据浏览器实际名为 **Codex**（Connectome Data Explorer），URL 为 [codex.flywire.ai](https://codex.flywire.ai)。"Codon" 应为误记。

## 1. FlyWire + Codex（Princeton，Murthy/Seung 实验室）

- **URL**：项目主页 [flywire.ai](https://flywire.ai/)；网页查询入口 [codex.flywire.ai](https://codex.flywire.ai)；neuroglancer 编辑界面 [ngl.flywire.ai](https://ngl.flywire.ai/)（校对/浏览，需申请编辑权限）。
- **数据内容**：基于 FAFB（Zheng et al. 2018）EM 体数据 + AI 自动分割 + 社区众包校对。论文版（Release 783）：**139,255 个校对后神经元、约 5000 万化学突触**；Codex 页面（2026-09-17 实测）列出 FAFB v783：139,255 neurons / 3,732,460 connections（"connections" 指经阈值过滤的神经元对连接）。约 56%（72,403 个）神经元已被社区标注细胞类型。神经递质预测来自 Eckstein et al. 2024。
- **Codex 托管的完整数据集列表**（2026-09-17 实测首页）：
  - **FAFB v783 (CB)**：雌性成年脑，139,255 neurons / 3,732,460 connections
  - **BANC v888 (CNS)**：雌性成年脑+腹神经索拼接，158,262 neurons / 3,037,361 connections
  - **MANC v1.2.1 (VNC)**：雄性腹神经索，23,665 neurons / 5,305,638 connections
  - **MAOL v1.1 (OL/R)**：雄性右侧视叶，52,445 neurons / 6,484,936 connections（Nern et al. 2025）
  - **MCNS v1.0 (CNS)**：雄性全中枢神经系统，166,700 neurons / 6,242,118 connections（Berg et al.）
- **注册与访问**：免费；网页查询需 Google 账户登录（无 Google 账户可邮件 flywire@princeton.edu 申请）。编程访问走 **CAVE**（Connectome Annotation Versioning Engine）：Python 客户端 **CAVEclient**（[github.com/CAVEconnectome/CAVEclient](https://github.com/CAVEconnectome/CAVEclient)，datastack 名素材中出现 `flywire_fafb_public` 与 `flywire_fafb_production` 两种写法，以官方文档为准）、**fafbseg**（[fafbseg-py.readthedocs.io](https://fafbseg-py.readthedocs.io/)）、R 端 **natverse/fafbseg**（[natverse.org/fafbseg](https://natverse.org/fafbseg/)）。CAVE 认证用全局 token。
- **典型查询**：Search（自由文本或结构化查询如 `class == olfactory`，按细胞类型/脑区/神经递质筛选）、Cell Details（上下游连接伙伴、3D 渲染）、Neuropils（按神经毡查询）、Pathways（最短路径分析）、Network Graphs、Stats、Download Data。批量下载 API：`https://codex.flywire.ai/api/download`（2026-09-17 实测 HTTP 200）。
- **文档/教程**：[Codex 源码 github.com/murthylab/codex](https://github.com/murthylab/codex)；[How To Use FlyWire for Connectomics（2024-12-20）](https://blog.flywire.ai/2024/12/20/how-to-use-flywire-for-connectomics/)；[Finding Paths in Codex](https://blog.flywire.ai/2024/12/20/finding-paths-in-codex/)；[Codex Query Master Workshop 录像（2025-10-29）](https://blog.flywire.ai/2025/10/29/codex-query-master-workshop/)；Codex 页脚内置 Sample Queries、FlyWire Academy。
- **其他访问通道**：CATMAID Spaces（[fafb-flywire.catmaid.org](https://fafb-flywire.catmaid.org/)）、braincircuits.io、neuroglancer 预配置场景。

## 2. neuPrint（Janelia FlyEM）

- **URL**：[neuprint.janelia.org](https://neuprint.janelia.org/)（neuPrint Explorer，2026-09-17 实测版本 1.72.0）；项目页 [janelia.org/project-team/flyem](https://www.janelia.org/project-team/flyem/hemibrain)。
- **数据内容**（API `GET /api/dbmeta/datasets` 2026-09-17 实测）：
  - **hemibrain:v1.2.1**——雌性半脑，~25,000 神经元，230 个 ROI
  - **manc:v1.0 / v1.2.1 / v1.2.3**——雄性腹神经索，~23,000 神经元
  - **optic-lobe:v1.0.1 / v1.1**——雄性右视叶，52,000+ 神经元
  - **male-cns:v0.9 / v1.0**——雄性全 CNS，~166,700 神经元（v1.0 于 2026-03-28 在 neuPrint 更新；**要雄性全 CNS 请优先用 v1.0** 而非 v0.9）
  - **mushroombody**——2017 年蘑菇体旧数据
- **注册与访问**：免费、CC-BY 许可；网页登录用 Google 账户，账户页获取 **auth token** 供 API 使用。客户端：Python **neuprint-python**（`pip install neuprint-python`）、R **neuprintr**（natverse 一部分）；底层为 Neo4j 图数据库，支持 **Cypher 查询语言**；可下载完整数据集通过 DVID 本地部署。
- **典型查询**：Explorer 内置 FindNeurons（按 cell type / ROI / 脑区）、Shortest Paths、FindSimilarNeurons（NBLAST 形态相似）；API 例：`fetch_neurons(NeuronCriteria(type='...'))`、查上下游连接伙伴、按 ROI 分解连接权重。
- **文档/教程**：[neuPrint 数据模型与 Cypher 手册（Janelia PDF）](https://www.janelia.org/sites/default/files/Project%20Teams/Fly%20EM/3.1%20191002_neuPrintManual-draft.pdf)；neuPrint 论文 Plaza et al. 2022（[PMC9350508](https://pmc.ncbi.nlm.nih.gov/articles/PMC9350508/)）；MANC 教程视频 [youtube.com/watch?v=FlpMlS9lixk](https://www.youtube.com/watch?v=FlpMlS9lixk)；[neuprint-python Quickstart](https://connectome-neuprint.github.io/neuprint-python/docs/quickstart.html)。
- **重要提示**：**FlyWire 数据不在 neuPrint 里**（FlyWire 走 CAVE/Codex 体系）；两套生态的 ID 映射靠 VFB 或 hemibrainr/nat 工具完成。

## 3. Virtual Fly Brain（VFB）

- **URL**：[virtualflybrain.org](https://www.virtualflybrain.org/)（v2 界面 v2.virtualflybrain.org）；英国团队（爱丁堡大学、剑桥/MRC LMB、EBI 等）。
- **数据内容**：定位是**数据整合枢纽**而非原始连接组生产者：把已发表文献中的神经解剖、基因表达、图像与连接组数据整合到同一套模板脑（JFRC2、JRC2018Unisex、Ito2014 等），用 OWL2 本体建模；每个神经元有持久 ID（VFB_xxxxxxxx），提供与 FlyWire / hemibrain / neuPrint bodyID 的**交叉引用**。托管数据集包括：FlyWire connectome neurons、JRC_FlyEM_Hemibrain v1.0.1/v1.1、MANC v1.0、optic_lobe:v1.0.1、FAFB 上数十个已发表稀疏重建集、L1 幼虫 EM 系列、FlyCircuit 1.0、FlyLight GAL4/LexA 图像集、单细胞 RNA-seq 集等。另托管 CATMAID 实例（l1em、fafb）。
- **注册与访问**：免费、无需登录即可浏览；编程访问：**vfb-connect**（Python，[PyPI](https://pypi.org/project/vfb-connect/)）、**VFBquery**（[GitHub](https://github.com/VirtualFlyBrain/VFBquery)）、R 端 **vfbr** 与 **vfbconnectr**（[natverse.org/vfbconnectr](https://natverse.org/vfbconnectr/)）；另提供 **VFB MCP Server**（vfb3-mcp.virtualflybrain.org，供 LLM agent 自然语言查询，2026 年新功能）。
- **典型查询**：按解剖本体术语查神经元类、按细胞类型查全部个体神经元、跨数据集找形态相似神经元、连接查询与路径查找、把 EM 神经元映射到 GAL4 driver line（找实验工具）。
- **文档/教程**：[VFB 文档中心](https://www.virtualflybrain.org/docs/)；[API 概览](https://www.virtualflybrain.org/docs/tutorials/apis/vfb_api_overview/)；资源论文 Court et al. 2023（[PMC9908962](https://pmc.ncbi.nlm.nih.gov/articles/PMC9908962/)）。**特别推荐**：[神经元计数口径文档](https://www.virtualflybrain.org/docs/concepts/neuron-counts/)——"数字怎么数"的权威说明。

## 4. FlyBase

- **URL**：[flybase.org](https://flybase.org/)；开发者文档 [flybase.github.io](https://flybase.github.io/)。
- **数据内容**：果蝇**遗传学与基因组学**核心数据库（非连接组）：基因、等位基因、表型、表达模式、转基因插入、stock 信息等。对连接组工作的价值：细胞类型 → 基因 / driver line（split-GAL4）的桥梁（配合 VFB 使用）。
- **注册与访问**：免费、网页查询（QuickSearch、BLAST、JBrowse、QueryBuilder）无需注册；编程访问有 REST API 与公开 Chado PostgreSQL 服务器；批量 flat-file 下载。
- **文档/教程**：[FlyBase TV YouTube 频道](https://www.youtube.com/c/FlyBaseTV)。
- **时效性警告（经费危机）**：2025 年 5 月 NIH 终止对哈佛大学的全部资助，殃及 FlyBase 的 NHGRI 资助；FlyBase 裁员并发起捐赠；2025 年 10 月 Wellcome 提供过渡资金，但长期前景未卜。引用时应注明该风险。（[FlyBase Substack 2025-08-22](https://flybase.substack.com/p/flybase-nih-grant)；[Nature 新闻 2025-10-02](https://www.nature.com/articles/d41586-025-03040-5)）

## 5. BrainCircuits.io

- **URL**：[braincircuits.io](https://braincircuits.io/)；功能说明页 [braincircuits.io/features](https://braincircuits.io/features)。
- **数据内容**：跨物种比较连接组学网页平台。首页（2026-09-17 实测）列出的果蝇数据集：Janelia Hemibrain、Janelia MANC（雄性 VNC）、Female Adult Brain – FlyWire（FAFB）、Female Adult Nerve Cord（FANC，雌性 VNC）；另有小鼠 MICrONS 视觉皮层示例。
- **访问方式**：纯网页、免费、无需编程；以 widget 组合式界面著称：按属性过滤神经元 3D 可视化、查上/下游突触伙伴、ROI 网格、网络图、把 EM 神经元变换到模板空间并与 GAL4 genetic line 匹配、跨数据集并排比较。
- **归属**：由果蝇连接组学社区开发（Galili et al. 2022 综述将其列为官方工具；FlyWire Nature 论文 Data availability 将其与 Codex、CATMAID Spaces 并列为非编程访问入口）；具体开发团队署名未在官网找到，**未证实**。

## 6. 其他相关门户

- **FANC**（Female Adult Nerve Cord，Lee lab Harvard + Tuthill lab UW）：CAVE 托管，CAVEclient 访问；[github.com/htem/FANC_auto_recon](https://github.com/htem/FANC_auto_recon)。
- **NeuronBridge**（[neuronbridge.janelia.org](https://neuronbridge.janelia.org/)）：LM（MCFO 图像）与 EM 形态相似匹配。
- **FruitFlyBrain / NeuroNLP**（hemibrain.neuronlp.fruitflybrain.org）：FlyBrainLab 生态的自然语言/图形化查询。
- **neuroglancer**（[github.com/google/neuroglancer](https://github.com/google/neuroglancer)）：上述各平台共同的底层 3D 查看器。
- **flyconnecto.me**（[工具清单页](https://flyconnecto.me/tools/)）：Philipp Schlegel 维护的果蝇连接组学工具导航（NAVis、fafbseg、natverse、rcatmaid、neuprintr 等）。
- **MICrONS Explorer**（[microns-explorer.org](https://www.microns-explorer.org)）：小鼠 1 mm³ 功能连接组。
- **关于 "Clandinin 门户"**：Clandinin lab（Stanford）没有独立的公开连接组查询门户（**未证实存在**）；其参与的女性视叶 FIB-SEM 数据经 neuPrint/Janelia 渠道发布，雄性视叶配套展示站为 reiserlab.github.io。建议以"Janelia optic-lobe / MAOL"替代该提法。

## 7. 选型速查（要查什么去哪）

| 需求 | 首选平台 |
|---|---|
| 全脑最新、雌性成蝇（Eon 演示同款） | FlyWire / Codex（FAFB v783），编程用 CAVEclient |
| 脑区级精确、成熟的 ROI 体系 | neuPrint hemibrain |
| 腹神经索（运动回路） | neuPrint MANC（雄）/ FANC（雌） |
| 雄性全 CNS（脑+VNC 一体，可商用许可） | neuPrint male-cns:v1.0（CC BY 4.0） |
| 雌性全 CNS | Codex BANC v888 |
| 跨数据集 ID 映射、找实验用 GAL4 line | Virtual Fly Brain |
| 基因/突变体/表达 | FlyBase |
| 零代码网页对比浏览 | BrainCircuits.io |
