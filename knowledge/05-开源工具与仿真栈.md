# 05 · 开源工具与仿真栈

> 来源：基于 2026-09-17 调研整理（GitHub 星数、PyPI 版本均为当日查询值）

果蝇连接组与仿真的可动手工具链，按用途分四组：A. 连接组数据获取与形态分析；B. 连接组 → 动力学模型；C. 躯体/具身仿真；D. 集成平台；另附 E. 对照项目 OpenWorm 与 F. 社区玩具项目。

## A. 连接组数据获取与形态分析（无需 GPU）

### CAVEclient —— 访问 FlyWire/BANC 版本化连接组的官方 Python 客户端
- 仓库：[CAVEconnectome/CAVEclient](https://github.com/CAVEconnectome/CAVEclient)，39★，MIT，活跃（最近提交 2026-09-05）
- 安装：`pip install caveclient`（PyPI 最新 8.2.1，2026-07-10，Python ≥3.9）
- 依赖：纯 HTTP 客户端（requests/pandas）；**不需要 GPU**；需免费注册 token
- 文档：[官方文档站](https://caveconnectome.github.io/CAVEclient)；[安装文档](https://caveconnectome.github.io/CAVEclient/installation/)；[Sven Dorkenwald 工作坊视频（57 分钟）](https://www.youtube.com/watch?v=B5EeqVlOqjk)

### neuprint-python —— Janelia neuPrint 的 Python 客户端
- 仓库/文档：[connectome-neuprint.github.io/neuprint-python](https://connectome-neuprint.github.io/neuprint-python/docs/)，70★，BSD-3，活跃（2026-07-20，PyPI 0.6.3）
- 安装：`pip install neuprint-python`；需在 neuprint.janelia.org 用 Google 账号登录取 API token；不需要 GPU
- R 版：natverse/neuprintr（14★）

### navis 生态（Python，natverse 的 Python 对应物）
- [navis-org/navis](https://github.com/navis-org/navis)：130★，GPL-3，活跃（2026-09-06；PyPI 1.12.0）。`pip install navis`，无需 GPU；内置示例神经元，开箱即用。文档：[navis.readthedocs.io](https://navis.readthedocs.io/)
- [navis-org/fafbseg-py](https://github.com/navis-org/fafbseg-py)：29★，FlyWire/FAFB 专用（mesh/skeleton/连接查询），`pip install fafbseg`（3.2.2）
- [navis-org/skeletor](https://github.com/navis-org/skeletor)：260★，mesh 骨架化
- [navis-org/navis-flybrains](https://github.com/navis-org/navis-flybrains)：34★，模板脑坐标变换（Nature 2024 论文官方推荐工具之一）

### natverse（R 生态）—— [natverse.org](https://natverse.org/)
- 安装：`install.packages('natmanager'); natmanager::install('core')` 或 `natmanager::install('natverse')`（完整版）；见 [natverse.org/install](https://natverse.org/install/)。部分功能经 reticulate 调用 Python（`fafbseg::simple_python()`）
- 核心包：nat 79★、fafbseg(R) 14★（非常活跃，2026-09-16）、hemibrainr 9★（2025-04 后放缓）、neuprintr 14★、[natverse/malecns](https://github.com/natverse/malecns) 527★（MaleCNS 发布后热度飙升）、coconatfly 11★（跨数据集比较）
- 无需 GPU；主要瓶颈是大数据集下载（FAFB 突触表约 4 GB）

### VFB_connect —— Virtual Fly Brain 编程接口
- 仓库：[VirtualFlyBrain/VFB_connect](https://github.com/VirtualFlyBrain/VFB_connect)，6★，GPL-3，活跃（2026-09-05）

### 图形界面入口（零代码）
- FlyWire Codex [codex.flywire.ai](https://codex.flywire.ai/)、Neuroglancer/Spelunker（[spelunker.cave-explorer.org](https://spelunker.cave-explorer.org/)）、neuPrint Web UI

## B. 连接组 → 动力学模型（rate model / LIF 的开源实现）

### philshiu/Drosophila_brain_model —— Shiu et al. Nature 2024 官方代码
- 仓库：[github.com/philshiu/Drosophila_brain_model](https://github.com/philshiu/Drosophila_brain_model)，307★，MIT；最后提交 2024-09-14（论文定格代码，非持续维护型项目）
- 安装：`conda env create -f environment.yml`，官方称约 10 分钟，Mac/Windows/Linux 均可；**不需要 GPU**（Brian2 CPU 模拟器，建议配置 C++ 代码生成加速）；README 顶部有 **Open in Colab** 徽章可零安装运行
- 最小示例：仓库内 `example.ipynb` 教激活/抑制神经元（模拟光遗传激活与沉默）；默认用 FlyWire v630，README 给出改 config 换 v783 的代码片段
- 功能边界：仅支持两类操纵（Poisson 激活两组神经元、将一组连接置零实现 silencing）；输出全体神经元的 spike times 与发放率

### eonsystemspbc/fly-brain —— Eon 开源的全脑 LIF 仿真与多后端基准
- 仓库：[github.com/eonsystemspbc/fly-brain](https://github.com/eonsystemspbc/fly-brain)，**803★**（创建于 2026-03-05，正值演示传播期），GPL-2.0-or-later，活跃（2026-08-29）
- 内容：以 Shiu 模型为蓝本（Brian2 CPU 为 "ground truth"），实现 **6 个后端**：Brian2（C++ standalone，CPU）、Brian2CUDA（GPU）、PyTorch（GPU/CPU）、NEST GPU（需源码编译）、GeNN（PyGeNN 5.4.0）、Brian2GeNN；带跨后端 spike 一致性比较工具与 5 轮基准套件
- 安装：`conda env create -f environment.yml && conda activate brain-fly`；数据（FlyWire v783，138,639 神经元精简打包）随仓库分发
- 计算需求：Linux（官方测试 Ubuntu 22.04/WSL2）、NVIDIA GPU + CUDA 12.x（测试用 RTX 4070）；仅 Brian2 CPU 后端可无 GPU 运行；提供 `scripts/setup_WSL_CUDA.sh`
- 最小可运行示例：`python main.py --brian2-cpu --t_run 1 --n_run 1 --no_log_file`（1 秒仿真、单试次、仅 CPU 后端）
- **重要边界**：该仓库只提供"脑"，**不包含 Eon 演示中的脑-体闭环集成代码**（awesome-fly 明确注释 "This repository supplies the neural model; it is not a complete embodied demo package"）。Eon 的具身闭环（下行神经元读取 → NeuroMechFly 控制器映射）截至 2026-09-17 未公开
- 相关 fork：[eonsystemspbc/drosophila_brain_model_lif](https://github.com/eonsystemspbc/drosophila_brain_model_lif)（10★）、[eonsystemspbc/flybody](https://github.com/eonsystemspbc/flybody)（17★）

### TuragaLab/flyvis —— Lappalainen et al. Nature 2024 官方实现
- 仓库：[github.com/TuragaLab/flyvis](https://github.com/TuragaLab/flyvis)，173★，MIT，活跃（2026-08-18；PyPI flyvis 1.2.0）
- 安装：`pip install flyvis`；提供 **Google Colab 快速上手**（7 个教程 notebook）；预训练模型可下载
- GPU：训练任务强烈建议 GPU；推理/分析可在 Colab 免费 GPU 上跑（纯 CPU 可行性**未证实**）
- 文档：[turagalab.github.io/flyvis](https://turagalab.github.io/flyvis/)；NeuroMechFly v2 的视觉系统即集成 flyvis

### YijieYin/connectome_interpreter —— 笔记本即可运行的全脑连接组分析
- 仓库：[github.com/YijieYin/connectome_interpreter](https://github.com/YijieYin/connectome_interpreter)，37★，MIT，活跃（2026-08-27）
- 安装：`pip install connectome-interpreter`；**笔记本/Colab 即可跑全脑（~14 万神经元）分析**，无需 GPU
- 功能：effective connectivity、path finding、可微发放率模型、梯度法（activation maximisation/saliency）、可视化；3 个 Colab 教程；一条命令把数据集从 FlyWire 换成 BANC/MaleCNS/hemibrain/MANC

### 其他动力学模型代码
- [emebeiran/connconstr](https://github.com/emebeiran/connconstr)（5★）：Beiran & Litwin-Kumar 2025 理论论文代码；数据在 [Zenodo 10.5281/zenodo.16618353](https://zenodo.org/records/16618353)
- [smpuglie/Pugliese_cpg_2025](https://github.com/smpuglie/Pugliese_cpg_2025)（星数未获取，**未证实**；正在改名 Pugliese_2026）：MANC 腹神经索 rate model，JAX/JIT + Hydra；`conda env create -f environment.yaml && pip install -e .`；CPU 可跑（4,604 神经元、2 s 仿真约 30–60 s），GPU 推荐 `pip install jax[cuda12]`

### 底层脉冲神经网络引擎
- [brian-team/brian2](https://github.com/brian-team/brian2)：1,231★，`pip install brian2`（2.10.1），纯 CPU 即可
- [brian-team/brian2cuda](https://github.com/brian-team/brian2cuda)：81★，GPU 扩展
- [nest/nest-gpu](https://github.com/nest/nest-gpu)：28★，需源码编译
- [genn-team/genn](https://github.com/genn-team/genn)：280★，GPU 代码生成式模拟器

## C. 躯体/具身仿真（"身体"方案）

### NeLy-EPFL/flygym（NeuroMechFly v2）—— EPFL 官方具身仿真框架，Eon 演示所用的"身体"
- 仓库：[github.com/NeLy-EPFL/flygym](https://github.com/NeLy-EPFL/flygym)，350★，Apache-2.0，活跃（2026-08-24）
- **2026-03/04 推出 2.x API 完全重写**：CPU ~10× 加速（~2× 实时）、GPU 经 Warp/MJWarp ~300× 加速（~60× 实时）；**不向后兼容**，旧版迁至 [flygym-gymnasium](https://github.com/NeLy-EPFL/flygym-gymnasium)
- 安装：`pip install "flygym"`（可选 extras：`flygym[examples]`、`flygym[dev]`）；或 Poetry；或 Docker（GPU 需 NVIDIA Container Toolkit）；支持 Linux/macOS/Windows；无显示器服务器需设 `MUJOCO_GL=egl`
- 组件：真实雌蝇 micro-CT 生物力学模型（87 个独立关节）、复眼视觉、嗅觉、层级控制（脑↔VNC 接口）、腿黏附、机械感觉反馈；MuJoCo 物理引擎
- GPU：基础仿真不需要；v2 的 MJWarp GPU 加速需 NVIDIA
- 最小示例：克隆仓库后 `uv run python scripts/launch_interactive_viewer.py` 启动交互 viewer；教程入口 [neuromechfly.org](https://neuromechfly.org/)
- 注意：FlyGym 2.x 与旧教程版本差异大，旧教程需对照版本（"check version-specific documentation"）

### TuragaLab/flybody —— Google DeepMind × Janelia 解剖级果蝇身体 + RL 任务
- 仓库：[github.com/TuragaLab/flybody](https://github.com/TuragaLab/flybody)，897★，Apache-2.0，最近提交 2026-02-07
- 安装：`pip install git+https://github.com/TuragaLab/flybody.git`（三档：核心 / `[tf]` ML 扩展 / `[ray]` 分布式 RL）；conda 环境 Python 3.10 + cudatoolkit 11.8；无显示器需 `MUJOCO_GL=egl`
- GPU：核心 MuJoCo 仿真不需要；RL 训练（DMPO + Ray）需要
- 最小示例（README 原文）：
```python
import numpy as np, mediapy
from flybody.fly_envs import walk_imitation
env = walk_imitation()
for _ in range(100):
    timestep = env.step(np.random.normal(size=59))  # 59 维行走动作空间
mediapy.show_image(env.physics.render(camera_id=1))
```
- Eon 明确说他们用的是 NeuroMechFly 而非 flybody

## D. 集成平台

### FlyBrainLab / FFBO（哥大 Aurel Lazar 组）
- 仓库：[github.com/FlyBrainLab/FlyBrainLab](https://github.com/FlyBrainLab/FlyBrainLab)，97★，BSD-3；最近提交 2025-09-29（**维护明显放缓**）；教程仓库 2022-11 后停更
- 定位：JupyterLab 内 3D 探索脑数据 → 构建 executable circuit → Neurokernel（GPU）执行；数据源含 hemibrain、FlyCircuit、L1 幼虫 EM
- 安装四档：①仅用户端组件（连官方公共后端，无需 GPU）；②完整安装（Ubuntu + **CUDA GPU 必需** + 30 GB 磁盘 + 建议 32 GB 内存）；③Docker：`docker run --gpus all -p 9999:8888 -it fruitflybrain/fbl:latest`；④AWS AMI
- 已知问题：eLife 审稿意见指出"安装说明不一致、上手困难"；**2025–2026 未检索到重大新版本发布（未证实有新进展）**
- 免安装体验：NeuroNLP 网页应用 fruitflybrain.org

## E. 对照项目：OpenWorm（线虫 C. elegans，302 神经元）

- 组织：[github.com/openworm](https://github.com/openworm)；主仓库 [openworm/OpenWorm](https://github.com/openworm/OpenWorm) **3,061★**，MIT，活跃（2026-08-04）
- 快速上手（官方 Docker 全家桶）：`git clone http://github.com/openworm/openworm && cd openworm && ./run.sh`（需 Docker、≥60 GB 磁盘、≥2 GB 内存；默认跑约 5% 时长，`-d 5000` 跑满 5 秒）；容器内同时运行 c302 神经系统模型与 Sibernetic 身体模型
- 子项目：[c302](https://github.com/openworm/c302)（156★，活跃）、[sibernetic](https://github.com/openworm/sibernetic)（393★，活跃）、[org.geppetto](https://github.com/openworm/org.geppetto)（217★，2021 年后基本停更）
- 文档：[docs.openworm.org](http://docs.openworm.org)；项目 2011 年启动，15 年仍在迭代
- **对照意义**：302 神经元做了 15 年仍未宣称"上传成功"，是评估 Eon 宣称的常用标尺
