# 06 · 动手教程（新手 step-by-step）

> 来源：基于 2026-09-17 调研整理

三个递进任务：① 注册并查询 FlyWire/Codex 连接组；② 用 neuPrint 查神经元连接；③ 跑全脑模型或身体仿真。

**重要约定**：本教程中的命令与代码**均直接引自已核实的调研素材**（官方 README/文档的原文示例），未在素材中出现的命令一律不写。标注"未核实"的步骤请自行以官方文档为准。所有平台均为免费。

## 任务 0：零代码先玩 5 分钟（可选）

不想写代码？先开两个网页：

1. **Codex**（[codex.flywire.ai](https://codex.flywire.ai)）：Google 账户登录 → 在 Search 里试结构化查询 `class == olfactory`（查所有嗅觉类神经元）→ 点任一神经元看 Cell Details（上下游连接伙伴、3D 渲染）。页脚的 Sample Queries 有现成示例。
2. **浏览器版全脑仿真** [snedea/flybrain](https://github.com/snedea/flybrain)：打开 `index.html` 即可在浏览器里跑 FlyWire v783 全脑 LIF 实时仿真，支持喂食/触摸/吹风交互（社区项目，MIT）。

## 任务 1：注册并查询 FlyWire 连接组（Python CAVEclient）

**目标**：用代码查询 FlyWire FAFB v783 连接组（139,255 神经元，Eon 演示的同款数据）。

### 1.1 注册与 token

1. 打开 [flywire.ai](https://flywire.ai/) 或 [codex.flywire.ai](https://codex.flywire.ai)，用 Google 账户登录（无 Google 账户可邮件 flywire@princeton.edu 申请）。
2. CAVE 认证使用全局 token；首次使用客户端时用 `client.auth.setup_token()` 完成设置（见下方代码注释）。token 获取流程参考 [MICrONs 的 CAVEclient 设置教程](https://tutorial.microns-explorer.org/quickstart_notebooks/01-caveclient-setup.html)。

### 1.2 安装

```bash
pip install caveclient
```

（PyPI 最新 8.2.1，2026-07-10，需 Python ≥3.9；纯 HTTP 客户端，不需要 GPU。）

### 1.3 最小示例（官方文档口径）

```python
from caveclient import CAVEclient
client = CAVEclient('flywire_fafb_production')   # 首次使用需 client.auth.setup_token()
client.materialize.get_versions()                # 列出可用快照版本（如 783）
```

> 注：调研素材中 datastack 名出现两种写法——`flywire_fafb_production`（工具调研的代码示例）与 `flywire_fafb_public`（平台调研的文字描述）。若一个不通，试另一个；以 [CAVE 官方文档](https://caveconnectome.github.io/CAVEclient) 为准。

### 1.4 进阶

- 版本化查询（materialization）：选 v783 快照可复现 Nature 2024 论文口径。
- 形态/连接分析可叠加 **fafbseg**（`pip install fafbseg`）与 **navis**（`pip install navis`）。
- 教程：[FlyWire 使用教程博客（2024-12-20）](https://blog.flywire.ai/2024/12/20/how-to-use-flywire-for-connectomics/)；[CAVE 工作坊视频（57 分钟）](https://www.youtube.com/watch?v=B5EeqVlOqjk)；[sjcabs/fly_connectome_data_tutorial](https://github.com/sjcabs/fly_connectome_data_tutorial)（R+Python 双版本，覆盖 BANC/FAFB/MANC/hemibrain/MaleCNS 五大数据集）。
- **常见坑**：大批量数据下载体积可观（FAFB 突触表约 4 GB）；注意数据许可 CC BY-NC 4.0（商用受限，2026-09-27 官网现行文本）。

## 任务 2：用 neuPrint 网页/API 查神经元连接

**目标**：查询 hemibrain（Janelia 半脑连接组，~25,000 神经元，脑区级精确）中的神经元与连接。

### 2.1 网页版（零代码）

1. 打开 [neuprint.janelia.org](https://neuprint.janelia.org/)，Google 账户登录。
2. 选数据集 `hemibrain:v1.2.1`（或 `male-cns:v1.0` 查雄性全 CNS）。
3. 用内置 **FindNeurons** 按 cell type / ROI 查神经元；**Shortest Paths** 查两神经元间最短路径；**FindSimilarNeurons** 按形态（NBLAST）找相似神经元。

### 2.2 Python API

1. 在 neuPrint 网页账户页获取 **auth token**。
2. 安装：

```bash
pip install neuprint-python
```

3. 最小示例（官方 Quickstart 口径）：

```python
from neuprint import Client, fetch_neurons, NeuronCriteria
client = Client('https://neuprint.janelia.org', dataset='hemibrain:v1.2.1', token='你的token')
neurons, roi = fetch_neurons(NeuronCriteria(type='DA1.*'))
```

### 2.3 进阶与常见坑

- 底层是 Neo4j 图数据库，可直接写 **Cypher** 查询：[Cypher 手册（Janelia PDF）](https://www.janelia.org/sites/default/files/Project%20Teams/Fly%20EM/3.1%20191002_neuPrintManual-draft.pdf)。
- R 用户用 natverse 的 neuprintr。
- **坑 1**：FlyWire 数据不在 neuPrint（走 CAVE/Codex 体系），跨生态 ID 映射用 VFB 或 hemibrainr。
- **坑 2**：雄性全 CNS 选 `male-cns:v1.0`（2026-03-28 更新），不要用旧的 v0.9。
- 教程：[MANC 教程视频](https://www.youtube.com/watch?v=FlpMlS9lixk)；[VFB 的 neuPrint 教程](https://www.virtualflybrain.org/docs/tutorials/apis/4_neuprint/)。

## 任务 3A：跑 Shiu 全脑 LIF 模型（Eon 演示的"大脑"）

**目标**：在本机（或 Colab）运行 Shiu et al. 2024 *Nature* 的全脑连接组 LIF 模型——127,400 个神经元的脉冲网络，CPU 即可。

1. 克隆仓库：[github.com/philshiu/Drosophila_brain_model](https://github.com/philshiu/Drosophila_brain_model)（307★，MIT）
2. 安装：

```bash
conda env create -f environment.yml
```

官方称约 10 分钟，Mac/Windows/Linux 均可；**不需要 GPU**（Brian2 CPU 模拟器，建议配置 C++ 代码生成加速）。

3. **零安装替代**：README 顶部有 "Open in Colab" 徽章，可直接在浏览器里跑。
4. 最小示例：仓库内 `example.ipynb` 演示两类操纵——Poisson 激活一组神经元（模拟光遗传激活）、将一组神经元连接置零（silencing）；输出全体神经元的 spike times 与发放率。
5. 默认数据为 FlyWire v630；README 给出改 config 换 v783 的代码片段。

**Eon 的多后端版**（想跑 GPU 基准）：[eonsystemspbc/fly-brain](https://github.com/eonsystemspbc/fly-brain)（803★，GPL-2.0）：

```bash
conda env create -f environment.yml && conda activate brain-fly
python main.py --brian2-cpu --t_run 1 --n_run 1 --no_log_file   # 1 秒仿真、单试次、仅 CPU 后端
```

数据（FlyWire v783，138,639 神经元）随仓库分发。GPU 后端（Brian2CUDA/PyTorch/NEST GPU/GeNN）需 Linux + NVIDIA GPU + CUDA 12.x（官方测试 RTX 4070），Windows 可用 WSL2（仓库提供 `scripts/setup_WSL_CUDA.sh`）。

> **边界提醒**：这些仓库只提供"脑"。Eon 演示中"脑→身体"的具身闭环集成代码**未开源**——你无法用公开代码复现演示视频中的完整闭环，只能复现脑模型本身（或用社区复现，见下）。

## 任务 3B：跑 FlyGym / NeuroMechFly 身体仿真（Eon 演示的"身体"）

**目标**：运行 EPFL 的果蝇数字孪生身体（87 关节，MuJoCo 物理）。

1. 仓库：[github.com/NeLy-EPFL/flygym](https://github.com/NeLy-EPFL/flygym)（350★，Apache-2.0）
2. 安装：

```bash
pip install "flygym"
```

（可选 `flygym[examples]`、`flygym[dev]`；支持 Linux/macOS/Windows；基础仿真**不需要 GPU**；无显示器服务器需设 `MUJOCO_GL=egl`。）

3. 最小示例（交互 viewer）：

```bash
uv run python scripts/launch_interactive_viewer.py
```

4. 教程入口：[neuromechfly.org](https://neuromechfly.org/)。

> **版本坑**：FlyGym 2.x（2026-03/04）API 完全重写、**不向后兼容**（CPU 提速 ~10×、GPU 经 MJWarp ~300×）。网上旧教程对应旧版（已迁至 flygym-gymnasium），照抄前务必核对版本。
>
> **未核实标注**：素材未提供"把 Shiu/Eon 脑模型接入 FlyGym 身体"的官方 step-by-step（Eon 的闭环代码未公开）。社区复现可参[erojasoficial-byte/fly-brain](https://github.com/erojasoficial-byte/fly-brain)（FlyWire v783 + NeuroMechFly v2，附 Zenodo 预印本）与 [a3xrfgb/synthetic-life-form 分步指南](https://github.com/a3xrfgb/synthetic-life-form/blob/main/STEP-BY-STEP-GUIDE.md)（本地跑 OpenWorm+Eon/Brian2+NeuroMechFly）——**这两个为社区材料，本知识库未逐步核实，请自行判断**。

## 任务 3C（可选）：flybody 与 flyvis

- **flybody**（DeepMind/Janelia 全身物理仿真 + RL，Nature 2025）：`pip install git+https://github.com/TuragaLab/flybody.git`；核心仿真不需要 GPU；最小示例见 `05-开源工具与仿真栈.md` C 节（README 原文代码）。
- **flyvis**（连接组约束视觉模型，Lappalainen et al. 2024 官方实现）：`pip install flyvis`；7 个 Colab 教程 notebook，预训练模型可下载；训练建议 GPU，推理可在 Colab 免费 GPU 跑。

## 任务 4（可选）：对照项目 OpenWorm（线虫，302 神经元）

体验"脑-体-环境"全闭环的经典对照（需 Docker、≥60 GB 磁盘）：

```bash
git clone http://github.com/openworm/openworm && cd openworm && ./run.sh
```

容器内同时运行 c302 神经系统模型与 Sibernetic 身体模型，输出图与视频；`-d 5000` 跑满 5 秒。文档：[docs.openworm.org](http://docs.openworm.org)。
