# 07 · 术语表（中英对照）

> 来源：基于 2026-09-17 调研整理

按主题分组，收录本知识库涉及的术语；释义基于调研素材中的用法。

## 连接组学基础

| 英文 | 中文 | 释义 |
|---|---|---|
| connectome | 连接组 | 一个神经系统中全部神经元及其突触连接的完整布线图 |
| connectomics | 连接组学 | 测绘、分析连接组的学科 |
| EM (electron microscopy) | 电镜（电子显微镜） | 纳米级分辨率脑成像技术，连接组数据的来源 |
| ssTEM | 连续切片透射电镜 | FAFB/FlyWire、BANC 所用成像路线（4×4×40 nm 级） |
| FIB-SEM | 聚焦离子束扫描电镜 | hemibrain、MANC、MaleCNS 所用路线（8 nm 各向同性体素） |
| segmentation | （自动）分割 | 用神经网络从 EM 图像中描出每个神经元轮廓的过程 |
| proofreading | 校对 | 人工修正自动分割错误；FlyWire 全脑约耗 33 人年 |
| annotation | 注释 | 给神经元标注细胞类型、脑区、发育谱系等属性 |
| synapse / synaptic contact | 突触 / 突触触点 | 神经元间连接点；注意与 neuron-pair connection（神经元对连接）口径不同 |
| T-bar / PSD | 突触前带 / 突触后致密区 | 电镜下识别的突触前/后结构（hemibrain：9.5M T-bars / 64M PSD） |
| cell type | 细胞类型 | 神经元的形态/连接类别；FlyWire 共 8,453 种 |
| neuropil | 神经毡 | 脑内突触密集的亚区（neuPrint 的 ROI 即按此划分） |
| hemilineage | 半谱系 | 果蝇神经元的发育来源分组 |
| projectome | 投射组 | 脑区之间的投射连接图（Dorkenwald et al. 2024 导出） |
| neurotransmitter prediction | 神经递质预测 | 用 CNN 从突触位点 EM 图像预测递质种类（Eckstein et al. 2024；单突触 87%/神经元 94%/细胞类型 91% 准确率）——为连接组边赋予兴奋/抑制符号 |
| NBLAST | 形态相似度算法 | 按神经元形态聚类/检索相似神经元（neuPrint FindSimilarNeurons 所用） |

## 脑解剖

| 英文 | 中文 | 释义 |
|---|---|---|
| central brain | 中枢脑 | 果蝇脑的中枢部分（不含视叶）；FlyWire 口径下完全位于中枢脑内的神经元约 32,388 个 |
| optic lobe | 视叶 | 脑两侧的视觉处理区；FlyWire 全脑 139,255 含两侧视叶 |
| VNC (ventral nerve cord) | 腹神经索 | 相当于脊髓，约 1.5 万（FANC 雌）–2.3 万（MANC 雄）神经元，行走/飞行运动中枢；Eon 演示未包含 |
| CNS (central nervous system) | 中枢神经系统 | 脑 + 腹神经索；MaleCNS/BANC 即全 CNS 连接组 |
| descending neurons (DN) | 下行神经元 | 脑 → VNC 的指令通道，全脑 1,000+ 个；Eon 手选 DNa01/DNa02（转向）、oDN1（前进速度）等作为"控制手柄" |
| motor neurons (MN) | 运动神经元 | 支配肌肉的神经元（如喙伸展 MN9） |
| mushroom body (MB) | 蘑菇体 | 果蝇学习与记忆中枢；Kenyon cell 是其主要神经元 |
| neck connective | 颈连合 | 脑与 VNC 之间唯一的连接通道 |
| lamina | 薄片层 | 视叶第一层神经节（BANC 数据集中缺失，约 9,390 个神经元） |

## 计算模型与仿真

| 英文 | 中文 | 释义 |
|---|---|---|
| LIF (leaky integrate-and-fire) | 泄漏积分发放（模型） | 最简脉冲神经元模型：输入漏积分到阈值即发放；Shiu/Eon 全脑模型所用，无可塑性、无树突计算 |
| spiking neural network | 脉冲神经网络 | 以离散脉冲（spike）传递信息的神经网络 |
| rate model | 发放率模型 | 以连续发放率（而非脉冲）描述神经元的简化模型（Pugliese CPG、connectome_interpreter 等所用） |
| connectome-constrained network | 连接组约束网络 | 连接结构固定为连接组、仅少量参数可学的网络（Lappalainen et al. 2024，734 个可学参数） |
| WBE (whole brain emulation) | 全脑仿真 | 在计算机中复现整个脑的功能；Sandberg & Bostrom 2008 路线图提出扫描→建模→仿真三阶段 |
| (mind/brain) uploading | （心智/脑）上传 | 把特定个体脑的信息内容迁移到计算机的强主张；本次事件的核心争议词 |
| embodiment / embodied | 具身（化） | 给脑模型接上（虚拟）身体与环境形成闭环；Eon 自称"第一次具身上传" |
| CPG (central pattern generator) | 中枢模式发生器 | 产生行走等节律运动的神经回路；WBE 派主张的仿真验证标志之一 |
| ring attractor | 环吸引子 | 果蝇头方向系统的环状动力学结构；内部动力学验证的另一标志 |
| gap junction | 间隙连接（电突触） | 直接的电耦合突触；现有连接组与仿真均不包含 |
| neuromodulator | 神经调质 | 调节神经网络状态的化学物质（如多巴胺）；Eon 模型未含 |
| plasticity | 可塑性 | 突触强度随活动改变的能力；Eon 的果蝇因无此而无法形成长期记忆 |
| expansion microscopy | 膨胀显微术 | 物理膨胀样本后用光镜达纳米分辨率；Eon 宣称的小鼠连接测绘手段 |
| proprioception / mechanosensory | 本体感觉 / 机械感觉 | 身体姿态与触觉反馈；FlyGym 身体含此类模拟 |

## 数据集与平台专名

| 名称 | 说明 |
|---|---|
| FAFB | Full Adult Fly Brain，成年雌蝇全脑 EM 体积（Zheng et al. 2018），FlyWire 的底层数据 |
| FlyWire | Princeton 的全脑连接组众包平台及其数据集（v783：139,255 神经元） |
| Codex | FlyWire 的网页数据浏览器（codex.flywire.ai）；**注意不是 "Codon"**（误记） |
| CAVE | Connectome Annotation Versioning Engine，FlyWire/BANC 的版本化数据后端；Python 客户端 CAVEclient |
| hemibrain | Janelia 半中枢脑连接组（Scheffer et al. 2020；neuPrint `hemibrain:v1.2.1`） |
| neuPrint | Janelia 连接组数据库（Neo4j 图数据库 + Cypher 查询） |
| MANC | Male Adult Nerve Cord，雄性腹神经索连接组 |
| FANC | Female Adult Nerve Cord，雌性腹神经索连接组 |
| MaleCNS / MCNS | 雄性全 CNS 连接组（2026，166,691 神经元，CC BY 4.0） |
| BANC | Brain And Nerve Cord，雌性"脑+VNC"一体连接组（2026，155,916 神经元） |
| MAOL / optic-lobe | 雄性右视叶连接组（Nern et al. 2025，MaleCNS 同一个体的子集） |
| VFB (Virtual Fly Brain) | 果蝇神经解剖本体与跨数据集整合枢纽 |
| FlyBase | 果蝇遗传学与基因组学核心数据库 |
| materialisation / materialization | CAVE 的数据快照版本机制（如 v630、v783） |
| datastack | CAVE 中一个数据集的命名入口（如 `flywire_fafb_production`） |
| GAL4 / split-GAL4 driver line | 果蝇遗传学中标记/操纵特定细胞类型的实验工具线 |

| 名称 | 说明 |
|---|---|
| MuJoCo | DeepMind 维护的开源物理引擎（Eon 演示与 FlyGym/flybody 的环境） |

| OpenWorm | C. elegans（302 神经元）全动物仿真开源项目，WBE 的先行对照 |
| MJWarp | MuJoCo 的 GPU（Warp）加速路径，FlyGym 2.x 提速来源 |
| neuroglancer | Google 的 3D 脑数据查看器，各平台共同底层 |

## 事件相关新词

| 词语 | 说明 |
|---|---|
| 电子果蝇 / 赛博果蝇 | 中文媒体对 Eon 具身仿真演示的称呼（"电子果蝇"见北方新报 2026-04-09 等） |
| puppet effect（木偶效应） | Koene 的批评术语：身体模型的代码在纠正脑模型的错误，行为看似来自脑实则来自身体 |
| railroaded simulation（铁轨式仿真） | Koene 的批评术语：环境简单到每步只有一个正确动作，无法检验脑是否真在决策 |
| flyslop | 2026-09 MaleCNS 发布后社区二创潮（Minecraft/Doom 等）的戏称 |
| digital twin（数字孪生） | Eon 工程负责人 Philip Shiu 自称更愿意用的词（替代"上传"） |
| MVP（最小可行产品） | Andregg 对本次"上传"的自我定位 |
| fidelity framework（保真度框架） | Eon 宣称正在起草的仿真验证标准 |
